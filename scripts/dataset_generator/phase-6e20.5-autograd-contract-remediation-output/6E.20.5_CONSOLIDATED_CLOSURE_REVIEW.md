## 2. Root-cause → fix mapping

- **Defect (Stage 6):** `run_phase_6e20_reevaluation.py:724` — `grads_s = torch.autograd.grad(s, lora_params, …)` where `s = z_pro` (line 705) = `float(probs[PRO_ID].item())` (line 712) ← `z_pro, z_abs = readout.forward_logits(hL)` returns `(float, float)` (legacy contract). A Python `float` cannot be differentiated → `TypeError: 'float' object is not iterable`.
- **Fix (6E.20.5, Option B):** add `Readout.forward_margin_tensor(hL)` / `forward_logits_tensor(hL)` returning a graph-connected `float64` `torch.Tensor` (mathematically identical to `forward_margin`/`forward_logits` within 1e-9); switch the **sole** `compute_live_rho_c` consumer to `forward_logits_tensor`. Legacy float contract and all frozen/prohibited paths left unchanged.
- **Why Option B (not A):** caller map proved Option A (global tensor return) had a large blast radius (`compute_decision_margin_and_metrics`, Stage 8 margins, 3 float-asserting tests). Option B is minimal (2 new methods + 1 caller line).

- `compute_live_cos_H1` (L604–608): after `result = crgc_fn(g_pos, g_abs)` it optionally stashes `list(g_pos)`/`list(g_abs)` into `_6E20_7_GRAD_CACHE` only when enabled, then `return float(result["cos_H1_aggregate"])` unchanged. - When disabled (default), both functions execute exactly as the pre-6E.20.7 baseline — zero behavioral difference.

### (2) telemetry_6e20_7 is purely additive and gated off unless explicitly enabled — PASS
- `_6E20_7_TELEMETRY_ENABLED = False` (L781, module default). `enable_6e20_7_telemetry(...)` (L796) is the sole opt-in and is NOT called anywhere in the default flow.
- Wiring guarded: `step_data["telemetry_6e20_7"]` (L1331–1332) and the classification block (L1358–1368) execute only when the flag is True. Default run produces no `telemetry_6e20_7` key and no `6e20_7_cause_classification.json`.

### (3) SENS uses exact pre-registered paraphrase set, real psdg_fn, canonical cos_H1_aggregate, >=0.95 criterion, pre-registered failure action — PASS (with one note)
- `run_6e20_7_sens_control` (L851–884): consumes `sens_prompts` as genuinely distinct framings (PRO at index `i`, ABS at `8+j`); computes `g_pos`/`g_abs` via the **real frozen `psdg_fn`** (L879, L882); returns `float(result["cos_H1_aggregate"])` (L884) from the frozen `crgc_fn` — the canonical definition. No gradient copying, no identity check.
- `>=0.95` criterion: `sens_ok = (sens_cos is None) or (sens_cos >= _6E20_7_SENS_EXPECT)` with `_6E20_7_SENS_EXPECT = 0.95` (L791, L940).

Thus SENS failure correctly blocks a false "valid" conclusion and changes no H1/P1–P6 verdict.
- **Note (non-blocking):** the explicit human decision "observable declared invalid for H1" is a governance action at authorization; the classification output would be clearer with an explicit `sens_passed` boolean. Recommended (not required) for the authorization wiring.
- **Binding of the EXACT paraphrase set:** the code consumes an externally-supplied `sens_prompts`; the exact pre-registered set is a governance artifact supplied by the future L5 authorization (not hardcoded, by design). The authorization step must pass the exact pre-registered set.

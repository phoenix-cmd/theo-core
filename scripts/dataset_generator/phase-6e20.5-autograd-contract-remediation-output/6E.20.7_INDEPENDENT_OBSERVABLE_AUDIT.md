## C. Sensitivity control — FIX REQUIRED (mathematical definition degenerate as written)
- **Problem:** Impl Section 2.3 / Spec Q5 define SENS as *reuse one framing's gradient for both*. Mathematically that yields `cosine(v, v) = 1.0` by construction — it validates the cosine function, NOT the observable's sensitivity to real data. It is degenerate and must not be the sole control.
- **Required pre-registered, non-degenerate definition:** `SENS` is a held-out probe set where PRO and ABS are *genuine linguistic paraphrases of the same verdict* (e.g., *The statement is true* vs *The statement is not false*). The model's naturally-computed `g_total` for the two framings is expected aligned. Compute `cos_H1_aggregate` on SENS with the REAL `psdg_fn` (no gradient copying). Pre-registered prediction: `cos_H1(SENS) >= 0.95`. If observed < 0.95, the observable cannot register compatibility present in the data → observable invalid (Spec Section 4).
- **Pre-registration requirement:** the SENS probe construction, the expected `>= 0.95`, and the fail-action must be frozen in the spec BEFORE telemetry is generated. The degenerate identity-check version is removed.

## E. Explicit criteria for the four named causes — FIX REQUIRED (per-sample heterogeneity not yet operationalized)

The requested four named categories map as: common-gradient dominance ≈ (b); low condition-specific signal ≈ (a/c); per-sample heterogeneity = NOT yet operationalized; genuine ~0.45 plateau ≈ (a) stable. Audit requires the following PRE-REGISTERED numeric criteria (diagnostic floors, separate from 0.80; floors fixed before data, not tuned to it):

Let per condition c, checkpoint t: `C_common = ||g_total_common||`, `C_spec = ||g_total_specific||`, `r_cs = C_spec/(C_common+eps)`, `V_het = std(cos_H1_i)`, `agg = cos_H1_aggregate`.
1. **Common-gradient dominance:** `C_common` large AND `r_cs < 0.20` while `agg ≈ 0.45` stable → plateau pinned by shared background; `g_total_specific` exists but is masked.
2. **Low condition-specific signal:** `C_spec` negligible in ABSOLUTE terms (e.g., `C_spec < floor_abs`) across S4/S8 regardless of `C_common` → intervention produced no framing-unique gradient. Distinguished from (1) by absolute `C_spec` being negligible vs merely small-relative.
3. **Per-sample heterogeneity:** `V_het > 0.25` OR multimodal `cos_H1_i` (substantial fraction near +1 and substantial fraction near <=0) so `agg` is a cancellation average → plateau is an averaging artifact, not a real value.
4. **Genuine ~0.45 plateau:** `agg ≈ 0.45` stable across steps (already r≈0.07), `V_het < 0.10`, `C_spec` non-negligible at a fixed stable angle, AND SENS control passes (`>= 0.95`) → 0.45 is a real stable compatibility value.

## 3. R2 — Controlled-Case Construction (Non-Tautological) — PASS

§4.0 now defines an **independent causal mechanism**:
- Controlled models `M` are synthetic readout modules conforming to the same `psdg_fn` interface, so the **frozen gradient machinery computes the gradients**; the readout **weights are the sole causal mechanism**, and **no compatibility label is attached**.
- Compatible (`M_compatible`): weights `W = P·S + E` with alignment by construction inside `P`; incompatible (`M_incompatible`): PRO/ABS placed in orthogonal/uncorrelated subspaces.
- **Mandatory independence requirement:** fixed documented seeds; the instrument's aggregation does **not** enter `W`; geometry is produced independently of the measured statistic. An instrument passes V2/V3 only by *genuinely measuring* the constructed geometry.
- Hold-out 24/6 split adds resistance to seed overfitting.

This resolves the prior UNKNOWN: the construction is now explicit and, as written, is non-tautological (the instrument sees only `(M, prompts)` and must discover alignment from gradients). → **PASS**.

## 9. Non-Blocking Implementation-Stage Notes (do NOT block advancement)

These are deferred to the synthetic-validation / implementation phase and do not invalidate the specification-level PASS:

1. **Synthetic-model interface feasibility (implementability):** §4.0 requires controlled `M` to conform to the *frozen* `psdg_fn` interface. It must be confirmed at implementation that the frozen `psdg_fn` computes gradients for an arbitrary synthetic readout module (and is not hard-coded to the real model's specific modules). If `psdg_fn` is architecture-specific, the construction method must be adapted (e.g., a thin wrapper exposing the same interface) — this is an implementation detail, not a specification defect.
2. **cos(θ_c) → measured-cos mapping:** V2's `≥ 0.90` floor assumes the measured `cos_H1` approximates `cos(20°) ≈ 0.9397`. Gradients are not identical to weights, and the `psdg_fn` + aggregation mapping is nonlinear, so the realized measured value should be characterized during the synthetic-validation phase. The pre-registered `0.90`/`0.85` floors were chosen *conservatively below* the ideal expectation to provide margin; if the realized mapping deviates substantially, the V2 threshold should be re-derived (still independently of H1's 0.80) and re-pre-registered before the read-only real-S4/S8 application.

Both notes are appropriately carried as open items into governance step 4 (synthetic/controlled validation), not as blockers for the specification.

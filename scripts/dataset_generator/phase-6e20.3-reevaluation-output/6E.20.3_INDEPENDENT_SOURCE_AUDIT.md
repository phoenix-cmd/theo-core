## Critical Finding (corrected during audit)

### F-1 — `compute_nepr_hash` excluded timestamp fields (DRIFT) — BLOCKING, NOW FIXED

**Spec (Revision 3 §4.1, lines 207–215):**
```python
def compute_nepr_hash(nepr_dict: dict) -> str:
    import hashlib, json
    d = dict(nepr_dict)
    d.pop("nepr_hash", None)
    canonical = json.dumps(d, sort_keys=True, separators=(',', ':'),
                           ensure_ascii=True, default=str)
    return "sha256:" + hashlib.sha256(canonical.encode("utf-8")).hexdigest()
```
**Spec property (§4.3, line 232):** *"nepr_hash excluded from its own computation (self-referential exclusion)."* — only `nepr_hash` is named as excluded.

**As-implemented (pre-correction):** the function additionally removed `category_F_metadata.nepr_timestamp_utc`, any `*timestamp*` key, and a top-level `timestamp_utc`, i.e. it excluded temporal fields from the hash contract.

**Finding:** Revision 3 does NOT authorize timestamp exclusion anywhere (§4.1, §4.3, §5 hash fields). Timestamps are declared *informational only* for **comparison gating** (Category D/F, §5.2/§9) — that is a separate concern from the hash contract. The implemented exclusion was a silent change to the canonical hash contract = specification drift, exactly as the reviewer predicted.

**Correction applied (`collect_nepr.py` `compute_nepr_hash`):** removed all timestamp-exclusion logic. The function now excludes ONLY `nepr_hash` (top-level and nested in `category_F_metadata`, the latter being where it actually lives in the NEPR structure — faithful to the spec's self-referential-exclusion intent). Timestamps (`nepr_timestamp_utc`, `env_timestamp_utc`) are now INCLUDED in the hash, matching §4.1/§4.3.

**Test corrected (`test_phase_6e20_reevaluation.py` Test 24):** renamed `nepr_hash_ignores_timestamp` → `nepr_hash_includes_timestamp`; it now asserts that differing `nepr_timestamp_utc` yields a DIFFERENT hash (the spec-correct behavior). Previously it asserted the drifted behavior and would have masked the defect.

**Re-verification:** 33/33 tests pass after correction.

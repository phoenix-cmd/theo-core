# 6E.20.4 — B0 Execution-Regime Remediation: Specification

- **Phase ID:** 6E.20.4
- **Parent investigation:** Runtime Drift Root-Cause Localization (post-6E.20.3 closure)
- **Status:** SPECIFICATION (pre-implementation; human L5 authorization + execution authorization required before code change)
- **Author:** agent (diagnostic phase)
- **Reviewer conclusion carried forward:** Root cause CONFIRMED — Stage 5 computes B0 live `cos(H1)` with the PEFT model in `train()` mode, activating `LORA_DROPOUT=0.05`; the historical B0 anchor `0.428355` was produced with dropout disabled (eval/inference mode).

---

## 1. Confirmed Root Cause (evidence summary)

| Item | Value |
|---|---|
| Historical anchor `B0` step-4 `cos(H1)` | `0.428355` |
| 6E.20.2 recomputation (Stage 5 halt) | `0.418701` (diff `9.65e-3`) |
| 6E.20.3 recomputation (Stage 5 halt) | `0.423468` (diff `4.89e-3`) |
| Tolerance `B0_REPRODUCIBILITY_TOLERANCE` | `1e-4` |
| TRAIN-mode (current) step-4 | stochastic, within-process diff `2.07e-4`–`4.36e-3` |
| EVAL-mode step-4 (3 independent processes) | `0.428355` **exactly**, bit-identical, matches anchor to the bit |
| First divergence boundary | LoRA dropout layer in `per_sample_decision_gradient` forward pass (frozen 6E.18 machinery `run_phase_6e18_causal_intervention.py:1008–1021`), active because the PEFT model is in `train()` at Stage 5 |
| Responsible factor | `LORA_DROPOUT = 0.05` active during gradient computation (inference-mode / Factor #3) |
| GPU nondeterminism | **Ruled out** (eval mode bit-identical on same CUDA device) |

The historical anchor was generated under the **deterministic dropout-off regime**; the evaluator reproduces it exactly when returned to that same regime. The divergence is a **regime mismatch**, not result corruption.

---

## 2. Remediation Objective

Restore the exact execution regime under which the immutable historical B0 anchor was originally generated, so that the Stage 5 B0 reproducibility computation runs with `LORA_DROPOUT` disabled (eval/inference mode), matching the anchor's generation regime.

**Goal is NOT to make B0 pass artificially.** It is to make the reproduction procedure consistent with the historical measurement. No tolerance, anchor, threshold, hypothesis evaluator, joint gate, or outcome matrix is changed.

---

## 3. Scope (smallest possible)

- **In scope:** the B0 reproducibility computation only — `compute_live_cos_H1` invocation inside `run_stage5_b0_historical_reproducibility_anchor` (`run_phase_6e20_reevaluation.py:768`).
- **Do NOT** globally move `model.eval()` to the whole pipeline unless evidence shows that is semantically safe. The repair is scoped to the B0 evaluation block.
- The change is purely an execution-regime guard (capture → eval → compute → restore). It does not alter any numerical formula, the frozen 6E.18 machinery, NEPR, or any scientific logic.

---

## 4. Exact Repair Approach

### 4.1 Location
`run_phase_6e20_reevaluation.py`, function `run_stage5_b0_historical_reproducibility_anchor`, the block at lines 766–770 (the `peft_model.load_state_dict(...)` followed by the `compute_live_cos_H1(...)` call).

### 4.2 Pseudocode (intended behavioral change)
```python
        peft_model.load_state_dict(ckpt["state_dict"], strict=False)

        was_training = peft_model.training
        try:
            peft_model.eval()
            # safeguard: confirm eval mode actually engaged
            if peft_model.training is not False:
                raise RuntimeError("B0 regime guard: model.eval() did not disable training mode")
            recomputed_cos = compute_live_cos_H1(
                peft_model, readout_s8, tokenizer, panel_prompts, psdg_fn, crgc_fn, device_str
            )
        finally:
            # restore the exact prior mode, exception-safe
            peft_model.train(was_training)
        # safeguard: confirm restoration
        if peft_model.training != was_training:
            raise RuntimeError("B0 regime guard: model mode not restored after B0 evaluation")
```

### 4.3 Rationale
- `nn.Module.eval()` (`peft_model.eval()`) recursively sets `training=False` on the PEFT model and all submodules (including the wrapped base model), disabling `LORA_DROPOUT`.
- `was_training` is captured immediately before and restored in `finally`, so subsequent pipeline stages observe exactly the mode they had before Stage 5.
- The `assert`/raise guards make any mode-regression loudly fail rather than silently corrupt.
- `compute_live_cos_H1` is unchanged; `ensure_readout_class_patch()` and the CUDA→numpy handling are unaffected.

## 5. Hard Constraints (inviolable)

Do NOT:
- modify tolerance `1e-4`;
- modify or replace anchor `0.428355`;
- average repeated runs;
- use best-of-N selection;
- introduce a correction factor;
- recompute the historical anchor;
- alter P1–P6 thresholds;
- alter `evaluate_protocol_hypotheses`;
- alter the joint success gate;
- alter the outcome matrix;
- modify frozen 6E.18 machinery (`psdg_fn`, `crgc_fn`);
- modify NEPR logic (`collect_nepr.py`);
- modify 6E.20.1 / 6E.20.2 artifacts.

### Rejected alternative (explicitly NOT chosen)
Recomputing the anchor under train mode and deriving a tolerance around ~`4e-3` is **rejected**. The evidence shows the historical anchor itself was produced under the deterministic dropout-off regime and the evaluator reproduces it exactly when returned to that regime. Replacing/altering the anchor or expanding tolerance would redefine the experiment instead of restoring consistency. The correct repair is to align the evaluator's regime with the anchor's, not to move the anchor to the evaluator's.

---

## 6. Required Implementation Safeguards

The repair MUST:
1. Record the model mode immediately before B0 evaluation (`was_training = peft_model.training`).
2. Explicitly call `peft_model.eval()` before `compute_live_cos_H1`.
3. Verify `peft_model.training is False` before entering the computation (raise if not).
4. Execute the B0 computation.
5. Restore the exact previous training state afterward:
   - previous `True` → restore train mode (`peft_model.train(True)`);
   - previous `False` → remain eval mode (`peft_model.train(False)`).
6. Verify restoration after computation (`peft_model.training == was_training`; raise if not).
7. Ensure exceptions cannot leave the model permanently in the wrong mode → `try/finally` (or equivalent exception-safe restoration).

## 1. Code Change 1 — B0 execution-regime guard

**File:** `run_phase_6e20_reevaluation.py`
**Function:** `run_stage5_b0_historical_reproducibility_anchor` (starts `:744`)
**Target:** the block at lines 766–770.

### 1.1 Exact replacement

Replace:
```python
        peft_model.load_state_dict(ckpt["state_dict"], strict=False)

        recomputed_cos = compute_live_cos_H1(
            peft_model, readout_s8, tokenizer, panel_prompts, psdg_fn, crgc_fn, device_str
        )
```

With:
```python
        peft_model.load_state_dict(ckpt["state_dict"], strict=False)

        # --- 6E.20.4 B0 execution-regime guard ---
        # The historical B0 anchor (0.428355) was generated with LoRA dropout
        # DISABLED (eval/inference mode). Running compute_live_cos_H1 in train()
        # mode activates LORA_DROPOUT=0.05 and makes cos(H1) stochastic (~1e-3),
        # which the 1e-4 reproducibility gate cannot satisfy. Restore parity by
        # evaluating under eval mode and restoring the prior mode afterward.
        was_training = peft_model.training
        try:
            peft_model.eval()
            if peft_model.training is not False:
                raise RuntimeError(
                    "6E.20.4 regime guard: model.eval() failed to disable training mode"
                )
            recomputed_cos = compute_live_cos_H1(
                peft_model, readout_s8, tokenizer, panel_prompts, psdg_fn, crgc_fn, device_str
            )
        finally:
            peft_model.train(was_training)
        if peft_model.training != was_training:
            raise RuntimeError(
                "6E.20.4 regime guard: model mode not restored after B0 evaluation"
            )
```

### 1.2 Notes
- `peft_model` is the **same object** passed into `compute_live_cos_H1` (the function parameter), so `eval()`/`train()` affect exactly the model used in the computation. No separate `base_model` handling needed; `nn.Module.eval()` recurses.
- `compute_live_cos_H1` only calls `ensure_readout_class_patch()` (does NOT mutate `training`); verified during the diagnostic phase. Therefore the post-restore assertion will hold.
- No other call site of `compute_live_cos_H1` (e.g., `:1042` Stage 7) is modified. If a later stage requires eval semantics it manages its own mode; this guard is scoped to Stage 5 only (scope isolation, Test G).
